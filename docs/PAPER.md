# Paper

This prototype is inspired by:

> Loi Ngo Duc Nguyen, Tahiatul Islam, Theron Wang, Sam Lenz, and Martin Kellogg.
> **Static Program Reduction via Type-Directed Slicing.**
> *Proceedings of the ACM on Software Engineering*, 2(ISSTA), Article ISSTA091, 2025.
> DOI: [10.1145/3728968](https://doi.org/10.1145/3728968)

The paper presents type-directed slicing for typechecker debugging and the
Specimin implementation for Java. This repository is an independent,
declaration-level prototype for Rocq/Coq; it is not the Specimin
implementation and does not implement the paper's full type-rule dependency
map.
